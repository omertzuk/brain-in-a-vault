# Generative process

A **generative process** is the real-world process that produces the sensory data received by an [[Agent]].

In [[Active Inference]], the [[Generative process]] belongs to the [[Environment]]. It is the actual process by which hidden states of the world generate observations.

In simple terms:

> The [[Generative process]] is the world producing sensory data.  
> The [[Generative model]] is the agent’s internal model of how that data was produced.

The agent does not directly observe the generative process. It only receives [[Sensory observations]]. From these observations, it must infer the hidden states that produced them.

## External states and outcomes

In the simple example from Chapter 2, the environment contains an [[External state]], written as `x*`.

This external state generates an [[Outcome]] or observation, written as `y`.

For example:

- `x*` may be the true size of a piece of food;
- `y` may be the light intensity reaching the agent’s sensors.

The agent does not directly observe the true food size. It only observes the sensory outcome.

So the environment generates `y`, and the agent must use `y` to infer `x*`.

This is the basic structure behind [[Hidden state estimation]].

## A simple linear generative process

To make the problem mathematically simple, the chapter begins with a very restricted generative process.

The assumptions are:

- the environment is [[Static environment|static]];
- there is one external state `x*`;
- there is one sensory observation `y`;
- the relationship between the state and the observation is [[Linear relationship|linear]];
- the state and observation are scalar quantities;
- there is no external state noise;
- the observation includes [[Gaussian noise]].

In this setting, the environment generates observations using a [[Linear generating function]] plus random noise.

## Equation 2.3: structural form of the generative process

The structural form of the generative process is:

$$
\mathcal{E} \triangleq
\begin{cases}
y = g_{\theta}(x;\theta^{*}) + \omega_{y}^{*}
& \text{OUTCOME GENERATION} \\[4pt]\hline

g_{\theta}(x;\theta^{*}) = \beta_{0}^{*} + \beta_{1}^{*}x
& \text{LINEAR GENERATING FUNCTION} \\[4pt]

\omega_{y}^{*} \sim \mathcal{N}(\mu = 0, \sigma^{2})
& \text{GAUSSIAN NOISE} \\[4pt]

\theta^{*} = [\beta_{0}^{*}, \beta_{1}^{*}]
& \text{PARAMETERS}
\end{cases}
$$

This says that the observation `y` is generated from the hidden state `x` by a linear function, with some random Gaussian noise added.

The linear function is:

$$
g_{\theta}(x;\theta^{*}) = \beta_{0}^{*} + \beta_{1}^{*}x
$$

Here:

- `β₀*` is the intercept;
- `β₁*` is the slope;
- `θ*` is the set of true environmental parameters;
- `ωᵧ*` is random noise added to the observation.

## Deterministic structure and probabilistic outcomes

The generating function itself is [[Deterministic]].

For a given value of `x`, the linear function always produces the same predicted value.

But the actual outcome `y` is [[Probabilistic]] because Gaussian noise is added.

This means that even if the external state is the same, the observation may vary from sample to sample.

For example, the same food size may usually generate a similar light intensity, but the exact sensory signal may fluctuate because of measurement noise, environmental variation, or imperfections in the sensory system.

## Why add noise?

Noise makes the model more realistic.

In real organisms, sensory observations are rarely exact. They are affected by:

- imperfect sensors;
- environmental variation;
- signal corruption;
- neural noise;
- uncertainty in measurement.

So the same external state may produce slightly different observations.

This is why the generative process is modeled as producing a distribution of possible observations rather than one perfectly fixed outcome.

## Structural form versus probabilistic form

The structural form shows the components of the process:

- the hidden state;
- the generating function;
- the noise term;
- the parameters.

But the same idea can also be expressed probabilistically.

Instead of saying that the outcome is generated by a function plus noise, we can say that the outcome is drawn from a probability distribution.

In the linear Gaussian case, the observation `y` is normally distributed around the value predicted by the generating function.

This means:

> The generating function gives the expected observation, and the noise describes how much actual observations vary around that expectation.

## Why this matters for Active Inference

The [[Generative process]] is important because it defines the hidden structure that the agent must learn or infer.

The agent receives only `y`, the sensory observation.

It does not directly receive `x*`, the true external state.

Therefore, the agent must build or use a [[Generative model]] that approximates the generative process.

This creates the central task of [[Perception]]:

> Infer the hidden state of the environment from the sensory outcome it generated.

This is also the basis of the [[Inverse problem]].

## Generative process versus generative model

The distinction is crucial.

The [[Generative process]] is the real process generating observations.

The [[Generative model]] is the agent’s model of that process.

In simulations, we may know both. We can define the generative process and then give the agent a model that tries to infer the hidden state.

But in real life, the organism does not have direct access to the true generative process. It must infer it from experience.

## Key idea

> A generative process is the actual environmental process that produces observations from hidden states.
