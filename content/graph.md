This page makes the site's link graph easier to find.

- To open the local graph for any note, view that note and look at the **Graph** panel in the right-hand sidebar.
- To open the global graph (all notes), click the small graph icon in the top-right of the local graph panel.

If the graph doesn't appear, ensure the Graph plugin is enabled in `quartz.config.yaml` (the `graph` plugin is included by default in this project). The graph requires the `content-index` plugin to be enabled so that link relationships are available.
